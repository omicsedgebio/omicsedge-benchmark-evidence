# Colab notebook boundary

`phase1a_colab_poc.ipynb` is a non-executing scaffold. It records the future
cell order and keeps `EXECUTE_COMPARISON = False`. The detailed, locked process
is in `docs/phase1a_compute_plan.md`.

No notebook output is committed. A future authorized compute session must save
its manifest, logs, checksums, validation report, and measured resources under
git-ignored `results/compute/`.
